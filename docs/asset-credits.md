# Visual asset notes

`public/images/learning-space.jpg` is used once as the homepage hero photograph. It was selected from the image search result titled “Student With Laptop Pictures | Download Free Images on Unsplash” (search position 5), which describes the result as a free Unsplash image. The downloaded project copy is kept local so the site does not rely on a temporary image-search URL. The image is not used as a course thumbnail or as evidence of any real Academi learner or instructor.

The small Academi open-book icon in `public/academi-icon.svg` is an original project SVG created for this application.
